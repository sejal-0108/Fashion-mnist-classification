# Fashion MNIST Classification using CNN & Streamlit

An end-to-end deep learning project that classifies clothing items using a Convolutional Neural Network (CNN) and presents predictions through an interactive Streamlit web application.

---

## 📊 Model Performance

- **Model Architecture:** 2D Convolutional Neural Network (CNN)
- **Dataset:** Fashion MNIST (70,000 images, 10 categories)
- **Accuracy:** ~91%
- **Loss:** ~0.25

---

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- Streamlit
- NumPy & Matplotlib
